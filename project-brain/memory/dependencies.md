# Memory Domain - Dependencies

## Backend Dependencies
*   `express (v5)` - REST server
*   `mysql2 (v3)` - Connect pool driver
*   `bcrypt (v6)` - Salted hashing
*   `jsonwebtoken (v9)` - JWT tokens
*   `cors` - Domain validation
*   `dotenv` - Env secrets config
*   `jimp (v0.22)` - Image pixel correction library

## Frontend Dependencies
*   `react (v18)` - Core DOM client
*   `react-router-dom (v6)` - client SPA routes
*   `axios` - HTTP bindings client
