# Project Brain v2 - Execution Workflow

## Lifecycle Progression
Defines the strict deterministic lifecycle of any engineering session prompt:

```
[User Prompt]
      ↓
[Task Classification]
      ↓
[Graph Context Retrieval]
      ↓
[Planning Specification]
      ↓
[Execution & Code Patching]
      ↓
[Static Verification / build checks]
      ↓
[Review and Audits (Score verification)]
      ↓
[Knowledge Synchronization]
```

*Ensure no validation step is bypassed during execution.*
